# Security Policy

## Supported versions

This is a community-maintained library. The maintainer applies security fixes to
the **latest released version** on Clojars. Upgrade to the latest release
before you report an issue.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, report them privately by email to **jsavyasachi@gmail.com**, or via
GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
("Report a vulnerability" under the repository's **Security** tab).

Include:

- a description of the issue and its effect,
- steps to reproduce it (or a proof of concept), and
- the affected versions.

You get a first reply in a reasonable time. After the maintainer confirms the
issue and releases a fix, the advisory becomes public. The advisory gives
credit to the reporter, unless you ask otherwise.
